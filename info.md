# Dynamic RadioCard

A 3D cover-flow media browser for **Music Assistant**: radio, podcasts,
tracks, albums and artists in a single Lovelace card — with provider filter,
grid view, player picker, volume and transport controls. English and German
UI built in.

**Requirements**

- Music Assistant with at least one player
- A Music Assistant long-lived token for the direct WebSocket connection

**Minimal configuration**

```yaml
type: custom:dynamic-radiocard
title: Music
ma_token: "eyJhbGciOi..."
```

Full documentation in the [README](https://github.com/badboiaustria/dynamic-radiocard).
